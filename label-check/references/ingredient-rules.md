# 配料表合规规则

> 详见 [gb28050-2025-summary.md](gb28050-2025-summary.md) 获取完整的营养成分表格式规范

## 常见合规问题

### 香精香料类

| 错误表述 | 正确表述 | 说明 |
|---------|---------|------|
| 食用香精 | 复合调味料 | 渠道接受度更高 |
| 食用香料 | 复合调味料 | 避免直接标注「香精」 |
| 香精 | 复合调味料 | 复合调味料为推荐表述 |

### 椰子相关配料

| 错误表述 | 正确表述 | 说明 |
|---------|---------|------|
| 椰子粉（固体饮料） | 烤椰粒（蜜饯） | 「固体饮料」易误导消费者 |
| 椰子粉 | 椰子粉（以实际情况为准） | 根据实际产品形态选择 |

### 食品添加剂

按 GB 2760 要求标注，以下为常见问题：

| 问题 | 正确处理 |
|------|---------|
| 标注不完整 | 确保所有添加剂均在配料表中列出 |
| 顺序错误 | 按添加量从高到低排序 |
| 未标注具体名称 | 使用标准添加剂名称 |

## 营养成分表格式要求（GB 28050-2025）

### 强制标示内容

| 营养成分 | 说明 |
|---------|------|
| 能量 | 必须标示，单位：kJ |
| 蛋白质 | 必须标示，单位：g |
| 脂肪 | 必须标示，单位：g |
| **饱和脂肪** | 必须标示，单位：g |
| 碳水化合物 | 必须标示，单位：g |
| **糖** | **2025版新增强制标示**，单位：g |
| 钠 | 必须标示，单位：mg |

### 2025版新增要求

| 要求 | 说明 |
|------|------|
| **糖强制标示** | 碳水化合物下的"糖"必须标示 |
| **健康提示语** | 必须标注：「儿童青少年应避免过量摄入盐油糖」 |
| **反式脂肪酸** | 使用氢化/部分氢化油脂时强制标示 |

### 营养成分表格式规范

1. **表格形式**：以"方框表"形式标示，与包装基线垂直
2. **表头**：「营养成分表」
3. **含量单位**：每100克(g)和/或每100毫升(mL)和/或每份可食部
4. **按"份"标示时**：必须标明每份食品的质量或体积
5. **NRV%**：强制标示营养成分必须标示NRV%

### "0"界限值速查

| 营养成分 | "0"界限值（每100g或100mL） |
|---------|--------------------------|
| 能量 | ≤17 kJ |
| 蛋白质 | ≤0.5 g |
| 脂肪 | ≤0.5 g |
| 饱和脂肪 | ≤0.1 g |
| 反式脂肪酸 | ≤0.3 g |
| 碳水化合物 | ≤0.5 g |
| 糖 | ≤0.5 g |
| 钠 | ≤5 mg |

### 允许误差范围

| 营养成分 | 允许误差 |
|---------|---------|
| 蛋白质、多不饱和/单不饱和脂肪、碳水化合物、膳食纤维、维生素、矿物质（不含钠） | **≥80%** 标示值 |
| 能量、脂肪、饱和脂肪、反式脂肪酸、胆固醇、钠、糖 | **≤120%** 标示值 |

### 修约间隔

| 营养成分 | 修约间隔 |
|---------|---------|
| 能量 | 1 kJ |
| 蛋白质、脂肪、碳水化合物、糖 | 0.1 g |
| 饱和脂肪、反式脂肪酸 | 0.1 g |
| 钠 | 1 mg |
| 维生素B1、B2、B6、B12 | 0.01 mg |
| 维生素C | 0.1 mg |

## 配料表审核检查清单

- [ ] 香精香料 → 是否改为「复合调味料」？
- [ ] 椰子相关配料 → 是否使用正确的产品形态标注？
- [ ] 营养成分表 → 数值是否有检测报告支撑？
- [ ] 添加剂名称 → 是否符合 GB 2760 要求？
- [ ] 配料排序 → 是否按添加量从高到低？
- [ ] **糖** → 是否已标示（2025版强制要求）？
- [ ] **健康提示语** → 是否标注「儿童青少年应避免过量摄入盐油糖」？
- [ ] **反式脂肪酸** → 使用氢化油脂是否标示？
- [ ] 数值修约 → 是否符合修约间隔要求？
- [ ] 误差范围 → 标示值与检测值是否符合允许误差？

## NRV%校验检查清单（⚠️ 容易出错）

- [ ] **确认标示单位** → 是「每100g」还是「每份Xg」？
- [ ] **每份折算** → 如为「每份」，是否已折算成「每100g」？
- [ ] **NRV%计算** → NRV%是否用「每100g」的数值计算？
- [ ] **典型陷阱** → 「每份40g，蛋白质2.9g，NRV%5%」是错误的！（正确为12%）

### 常见错误示例

| 标签标示 | 错误计算 | 正确计算 |
|---------|---------|---------|
| 每份40g，蛋白质2.9g，NRV%5% | 2.9÷60×100%=5% ❌ | 先折算7.25g/100g，再算12% ✅ |
| 每份30g，脂肪10g，NRV%17% | 10÷60×100%=17% ❌ | 先折算33.3g/100g，再算56% ✅ |
