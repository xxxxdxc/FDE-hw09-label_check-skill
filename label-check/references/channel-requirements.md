# 渠道特殊要求

## 线下渠道 vs 线上渠道

| 要求 | 线上渠道 | 线下渠道 |
|------|---------|---------|
| 型式检测报告 | 可选 | **必须** |
| 营养成分检测 | 可选 | **必须** |
| 标签报告 | 基本要求 | **必须** |
| 第三方检测 | 推荐 | **必须** |
| 低GI宣称 | 需提供依据 | 基本不允许 |
| 有机标识 | 需认证证书 | 需认证证书 |

## 检测周期参考

| 报告类型 | 周期 | 说明 |
|---------|------|------|
| 型式检测 | ~10工作日 | 收到样品后开始计算 |
| 营养成分检测 | ~10工作日 | 收到样品后开始计算 |
| 标签报告 | ~4工作日 | 提供包装展开图后开始 |
| 第三方检测 | 按实际 | 时间较长，需提前规划 |

## 线下渠道特别注意事项

### 低聚果糖/聚葡萄糖

**标注规则**：
- 低聚果糖如有特别说明，需要**标注含量**
- 低聚果糖和聚葡萄糖同时使用时，均按**益生元**说明处理

**示例**：
```
配料表标注：低聚果糖（添加量≥X%）
或
配料表标注：聚葡萄糖（添加量≥X%）
```

### 量贩零食渠道要求

根据产品类型确认：
- 规格要求（克重、包装形式）
- 售价要求（零售价、供货价）
- 资质要求（检测报告、授权文件）

### 精品超市渠道要求

- 包装需要通过渠道审核
- 价格体系需要确认
- 促销机制需要提前沟通
