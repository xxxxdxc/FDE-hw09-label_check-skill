# 文字校对规则

## 概述

文字校对是标签质检的重要环节，用于检测文案中的错别字、遗漏文字、多字及表达不顺畅的句子。

## 校对检查项目

### 1. 错别字检测

常见错别字对照：

| 错误 | 正确 | 说明 |
|------|------|------|
| 什锦 | 什锦 | 部分地区混淆 |
| 箱假 | 休假 | 形近错误 |
| 椰子粉 | 椰子粉 | 注意产品类型标注 |
| 复函 | 复核 | 形近字混淆 |
| 净含量 | 净含量 | 易写成"静含量" |
| 规格 | 规格 | 易写成"规各" |
| 生产日期 | 生产日期 | 易写成"生产日期" |
| 保质期 | 保质期 | 易写成"保质其" |
| 配料表 | 配料表 | 易写成"配量表" |

### 2. 营养成分单位规范

| 错误 | 正确 | 说明 |
|------|------|------|
| 大卡 | 千卡(kcal) | 能量单位 |
| 卡 | 千焦(kJ) | 能量单位 |
| 毫克g | 毫克(mg) | 单位错误 |
| 100%克 | 100g | 位置错误 |
| 每100%克 | 每100g | 表述错误 |
| 每100毫升 | 每100mL | 应使用mL |
| 每份30g/3片 | 每份30g（3片） | 括号规范 |

### 3. 食品名称规范

| 问题类型 | 示例 | 正确做法 |
|---------|------|---------|
| 产品名称模糊 | "美味零食" | 应使用具体产品名称 |
| 品类名称错误 | "固体饮粉" | 应为"固体饮料"或"固体饮料粉" |
| 谐音滥用 | "某零食品牌"（零食） | 可能涉及不良谐音 |
| 绝对化表述 | "最好吃" | 违反广告法 |

### 4. 配料表常见错误

| 错误 | 正确 | 说明 |
|------|------|------|
| 食用香精 | 复合调味料 | 规范表述 |
| 氢化植物油 | 氢化植物油（含反式脂肪酸需标注） | 需注意反式脂肪酸标示 |
| 白砂糖，蔗糖 | 蔗糖 | 避免重复标注 |
| 添加剂① | 需列出具体名称 | 不能用序号代替 |

### 5. 表达不顺畅检测

检查句子是否存在以下问题：

| 问题类型 | 示例 | 修改建议 |
|---------|------|---------|
| 语序不当 | "玉米片的酥脆香甜" | "酥脆香甜的玉米片" |
| 成分残缺 | "高蛋白0添加" | "高蛋白、0添加" |
| 语义重复 | "非常独一无二" | "独一无二"或"非常独特" |
| 搭配不当 | "提高免疫力" | 需确认是否为保健品功能 |
| 表述歧义 | "不含任何添加剂" | 可能与实际配料冲突 |

### 6. 标点符号规范

| 问题 | 正确 | 说明 |
|------|------|------|
| 连续使用逗号 | 使用顿号分隔 | 列表项分隔 |
| 英文逗号混用 | 统一使用中文标点 | 标签应使用中文标点 |
| 缺少顿号 | "蛋白质脂肪碳水化合物" | 应为"蛋白质、脂肪、碳水化合物" |

## 常见校对问题清单

### 必检项目

- [ ] 错别字：逐字检查，特别注意形近字
- [ ] 营养成分单位：kJ、g、mg、μg 是否正确
- [ ] 数值修约：保留小数位数是否符合 GB 28050
- [ ] 配料名称：是否符合 GB 7718 命名规范
- [ ] 标点符号：是否使用中文标点
- [ ] 产品名称：是否与食品标准一致

### 重点关注

- [ ] "0"界限值附近的数值（如 0.5g 糖）
- [ ] NRV% 计算是否正确
- [ ] 能量计算是否正确（蛋白质×17 + 脂肪×37 + 碳水化合物×17 + 膳食纤维×8）
- [ ] 反式脂肪酸是否在使用氢化油脂时标注

### 能量计算辅助校验

> 详见 [gb28050-2025-summary.md](gb28050-2025-summary.md) 完整计算示例

**快速验算公式：**
```
能量(kJ) = 蛋白质×17 + 脂肪×37 + 碳水化合物×17 + 膳食纤维×8
```

**kJ 与 kcal 换算：**
```
1 kcal = 4.184 kJ
能量NRV = 8400 kJ = 2000 kcal
```

**校验步骤：**
1. 提取营养成分表中的蛋白质、脂肪、碳水化合物、膳食纤维数值
2. 代入公式计算理论能量值
3. 与标签标示的能量值对比
4. 允许误差：计算值 × 120% ≥ 标示值

### NRV%计算辅助校验

> ⚠️ **关键前提**：以下快速计算公式仅适用于**每100g/100mL**的含量值。如标签以「每份Xg」标示，必须先折算成每100g再计算！
> 折算公式：`每100g数值 = 每份数值 × (100 ÷ 每份克数)`

**快速计算公式：**
```
NRV% = (每100g含量值 ÷ NRV) × 100%
```

**常用营养素快速计算（⚠️ 仅适用于每100g数值）：**
| 营养素 | 快速计算 |
|--------|---------|
| 能量 | ÷ 84 |
| 蛋白质 | × 1.67 |
| 脂肪 | × 1.67 |
| 碳水化合物/糖 | ÷ 3 |
| 钠 | ÷ 20 |
| 饱和脂肪 | × 5 |
| 膳食纤维 | × 4 |
| 钙 | ÷ 8 |

**校验步骤：**
1. 提取标示的NRV%值
2. **确认标示单位**：是「每100g」还是「每份Xg」
3. **如为「每份」**：先折算成每100g（每100g = 每份值 × 100 ÷ 每份克数）
4. 用**每100g**含量值计算理论NRV%
5. 对比计算值与标示值
6. 检查NRV%是否为整数

> ⚠️ **常见错误**：每份40g蛋白质2.9g，标签NRV%显示5%。
> 错误：2.9÷60=4.8%≈5% ✓（直接用每份值算，看似正确但错了！）
> 正确：先折算 2.9×(100÷40)=7.25g/100g，再算 7.25÷60=12%。标签5%是错的。
