# 宣称风险等级与处理建议

> 详见 [gb28050-2025-summary.md](gb28050-2025-summary.md) 获取完整的含量声称量化标准

## 🔴 高风险宣称（避免使用）

| 宣称 | 风险说明 | 正确处理 |
|------|---------|---------|
| 有机/有机认证 | 需提供有机认证证书，线上渠道通常不可使用 | 无证书则删除 |
| 无添加/0添加 | 需明确「无添加」具体是什么，提供检测依据 | 改为具体说明如「0防腐剂」 |
| 低GI | 涉及功能性宣称，监管严格 | 用「高膳食纤维」替代 |
| 益生元 | 需提供功能性依据 | 避免使用或提供检测报告 |
| 无糖/无蔗糖 | 需符合GB 28050要求（≤0.5g/100g） | 确保符合定义，提供检测依据 |

## 🟡 中风险宣称（确保达标）

| 宣称 | 风险说明 | 正确处理 |
|------|---------|---------|
| 高蛋白 | 需达到含量要求（每100g≥20%NRV，即≥12g） | 提供检测报告 |
| 高膳食纤维 | 需达到含量要求（每100g≥6g） | 提供检测报告 |
| 无蔗糖 | 与「无糖」不同，但仍需规范 | 明确标注「无蔗糖添加」 |
| 轻负担/低卡 | 涉及营养含量要求（低能量≤170kJ/100g） | 确保符合相关标准 |
| 低糖 | 需≤5g/100g | 提供检测报告 |
| 低钠 | 需≤120mg/100g | 提供检测报告 |
| 低脂肪 | 需≤3g/100g(固体)或≤1.5g/100mL(液体) | 提供检测报告 |

## 🟢 低风险宣称（基本可用）

| 宣称 | 风险说明 | 正确处理 |
|------|---------|---------|
| 工艺描述 | 如「第3代玉米提粗工艺」 | 可用，建议突出卖点 |
| 口味表述 | 如「蒜香」「芝士」等 | 基本可用，确保真实 |
| 原料描述 | 如「选用东北玉米」 | 可用，确保属实 |
| 蛋白质来源 | ≥10%NRV/100g | 可用，确保达标 |
| 膳食纤维来源 | ≥3g/100g | 可用，确保达标 |

## 含量声称量化标准速查（GB 28050-2025）

### 能量

| 声称方式 | 含量要求 |
|---------|---------|
| 无/零/无卡路里 | ≤17 kJ/100g(固体)或100mL(液体) |
| 低能量 | ≤170 kJ/100g(固体)或≤80 kJ/100mL(液体)，且脂肪供能比≤50% |

### 蛋白质

| 声称方式 | 含量要求 |
|---------|---------|
| 来源/含有蛋白质 | ≥10% NRV/100g(固体)或≥5% NRV/100mL(液体) |
| 高/富含蛋白质 | ≥20% NRV/100g(固体)或≥10% NRV/100mL(液体) |

### 脂肪

| 声称方式 | 含量要求 |
|---------|---------|
| 无/不含脂肪 | ≤0.5 g/100g或100mL |
| 低脂肪 | ≤3 g/100g(固体)或≤1.5 g/100mL(液体) |
| 瘦 | 脂肪≤10 g/100g，仅限畜肉类和禽肉类 |
| 无/不含饱和脂肪 | ≤0.1 g/100g或100mL |
| 低饱和脂肪 | ≤1.5 g/100g(固体)或≤0.75 g/100mL(液体)，且饱和脂肪供能比≤10% |
| 无/不含反式脂肪酸 | ≤0.3 g/100g或100mL |

### 糖

| 声称方式 | 含量要求 |
|---------|---------|
| 无/不含糖 | ≤0.5 g/100g或100mL |
| 低糖 | ≤5 g/100g或100mL |
| 无乳糖 | ≤0.5 g/100g(mL)，仅限乳品类 |

### 钠

| 声称方式 | 含量要求 |
|---------|---------|
| 无/不含钠 | ≤5 mg/100g或100mL |
| 极低钠 | ≤40 mg/100g或100mL |
| 低钠/低盐 | ≤120 mg/100g或100mL |

### 维生素/矿物质

| 声称方式 | 含量要求（每100g） |
|---------|-------------------|
| X来源/含有X | ≥15% NRV(固体)或≥7.5% NRV(液体) |
| 高/富含X | ≥30% NRV(固体)或≥15% NRV(液体) |

## 声称同义语

| 声称 | 同义语 |
|------|-------|
| 无、不含 | 零(0)、没有 |
| 低 | 少 |
| 来源、含有 | 提供、含、有 |
| 高、富含 | 良好来源、含丰富XX、丰富(的)XX、富 |
| 减少 | 减、减低、减少X%、减X%、降X%、降低X% |
| 增加 | 增、加、增高、增加X%(X倍)等 |

## 敏感宣称快速检查清单

检查标签时，逐项确认：

- [ ] 「有机」「有机认证」标识 → 是否提供证书？
- [ ] 「0添加」「无添加」→ 具体指什么？有依据吗？
- [ ] 「低GI」「益生元」→ 有检测报告吗？
- [ ] 「高蛋白」→ ≥20%NRV（≥12g/100g）？
- [ ] 「高膳食纤维」→ ≥6g/100g？
- [ ] 「无糖」→ ≤0.5g/100g？
- [ ] 「低钠」「低盐」→ ≤120mg/100g？
- [ ] 「低脂肪」→ ≤3g/100g(固体)？
- [ ] 反式脂肪酸 → 使用氢化油脂是否标示？
