# GB 28050-2025 核心摘要

> 食品安全国家标准 预包装食品营养标签通则  
> 发布日期：2025-03-16 | 实施日期：2027-03-16

## 强制标示内容

| 营养成分 | 说明 |
|---------|------|
| 能量 | 必须标示 |

| 脂肪 | 必须标示 |

| 碳水化合物 | 必须标示 |

## 能量计算公式

### 能量换算系数

| 成分 | 能量换算系数 |
|------|-------------|
| 蛋白质 | 17 kJ/g |
| 脂肪 | 37 kJ/g |
| 碳水化合物 | 17 kJ/g |
| 膳食纤维 | 8 kJ/g |

### 能量计算公式

```
能量(kJ) = 蛋白质(g) × 17 + 脂肪(g) × 37 + 碳水化合物(g) × 17 + 膳食纤维(g) × 8
```

### kJ 与 kcal 换算

| 换算关系 |
|---------|
| 1 kcal = 4.184 kJ |
| 1 kJ ≈ 0.239 kcal |
| 能量NRV = 8400 kJ = 2000 kcal |

### 计算示例

假设某产品每100g含：
- 蛋白质：10g
- 脂肪：20g
- 碳水化合物：60g
- 膳食纤维：5g

**计算过程：**
```
能量 = 10 × 17 + 20 × 37 + 60 × 17 + 5 × 8
     = 170 + 740 + 1020 + 40
     = 1970 kJ

换算kcal：1970 ÷ 4.184 ≈ 471 kcal

NRV% = 1970 ÷ 8400 × 100% ≈ 23%
```

### 校验规则

1. **允许误差**：能量标示值 ≤ 实测值 × 120%
2. **修约间隔**：能量单位为 kJ，修约间隔为 1
3. **NRV%修约**：NRV%修约间隔为 1

### 快速校验表

| 营养成分 | 计算贡献 | NRV占比 |
|---------|---------|--------|
| 蛋白质每1g | 17 kJ | 17÷8400×100% ≈ 0.2% |
| 脂肪每1g | 37 kJ | 37÷8400×100% ≈ 0.44% |
| 碳水化合物每1g | 17 kJ | 17÷8400×100% ≈ 0.2% |
| 膳食纤维每1g | 8 kJ | 8÷8400×100% ≈ 0.095% |

## NRV百分比计算

### 计算公式

```
NRV% = (营养素含量标示值 ÷ 营养素参考值) × 100%
```

### 校验规则

| 检查项 | 规则 |
|--------|------|
| 修约间隔 | NRV% 必须为整数（间隔为1） |
| 未规定NRV的营养成分 | NRV% 可为空白或用横线表示 |
| 能量误差 | 标示值 ≤ 计算值 × 120% |
| 蛋白质等误差 | 标示值 ≥ 计算值 × 80% |

### 常用营养素NRV%快速计算

| 营养素 | NRV | 每1单位贡献NRV% |
|--------|-----|----------------|
| 能量 | 8400 kJ | ÷84 = NRV% |
| 蛋白质 | 60 g | ×1.67 = NRV% |
| 脂肪 | 60 g | ×1.67 = NRV% |
| 饱和脂肪 | 20 g | ×5 = NRV% |
| 碳水化合物 | 300 g | ÷3 = NRV% |
| 糖 | 300 g | ÷3 = NRV% |
| 钠 | 2000 mg | ÷20 = NRV% |
| 膳食纤维 | 25 g | ×4 = NRV% |
| 钙 | 800 mg | ÷8 = NRV% |
| 铁 | 15 mg | ×6.67 = NRV% |
| 锌 | 11 mg | ×9.09 = NRV% |

### NRV%计算示例

**示例1：蛋白质NRV%计算**
```
标示值：10g蛋白质
NRV = 60g
NRV% = 10 ÷ 60 × 100% = 16.67% → 修约为 17%
```

**示例2：钠NRV%计算**
```
标示值：400mg钠
NRV = 2000mg
NRV% = 400 ÷ 2000 × 100% = 20%
```

**示例3：碳水化合物NRV%计算**
```
标示值：60g碳水化合物
NRV = 300g
NRV% = 60 ÷ 300 × 100% = 20%
```

### NRV%校验步骤

1. 提取营养成分表中的含量值和NRV%
2. **确认标示单位**：是「每100g」还是「每份Xg」
3. **如果是「每份」**：必须先折算成「每100g」，再用每100g的数值计算NRV%
4. 用折算后的含量值计算理论NRV%
5. 对比计算值与标示NRV%（允许±1修约误差）
6. 检查是否在允许误差范围内

### ⚠️ 关键陷阱：「每份」标示的NRV%错误

**常见错误**：标签以「每份Xg」标示，但NRV%却用「每份」的数值直接计算，而不是折算成「每100g」后再计算。

**正确做法**：
```
1. 先把「每份」的数值折算成「每100g」
   每100g数值 = 每份数值 × (100 ÷ 每份克数)

2. 再用「每100g」的数值计算NRV%
   NRV% = (每100g含量 ÷ NRV) × 100%
```

**示例：蛋白质NRV%正确计算**
```
标签：每份40g，蛋白质2.9g，NRV%显示5%

错误计算：
2.9g ÷ 60g × 100% = 4.8% ≈ 5% ✓ (这是错的！)

正确计算：
Step 1：折算每100g → 2.9 × (100÷40) = 7.25g/100g
Step 2：计算NRV% → 7.25 ÷ 60 × 100% = 12.1% ≈ 12%
         标签显示：5% ❌ 错误！

结论：此标签的蛋白质NRV%标注错误！
```

## 允许误差范围

## 豁免强制标示的食品

1. 生鲜食品和粮食籽粒（畜禽肉、鱼虾蟹贝、鲜蛋、蔬菜水果等）
2. 经简单物理处理、未添加其他配料的单一原料干制品
3. 包装饮用水、茶叶
4. 酒精度在0.5%vol以上的饮料酒
5. 每日食用量≤10g(mL)的预包装食品和单一原料调味品
6. 包装物或包装容器的最大表面面积≤40cm²的食品
7. 其他法律法规和食品安全国家标准规定的

## 含量声称量化标准

### 能量声称

| 声称 | 条件 |
|------|------|
| 无能量/零能量 | ≤17 kJ/100g(固体) 或 100mL(液体) |
| 低能量 | ≤170 kJ/100g(固体) 或 ≤80 kJ/100mL(液体)，且脂肪供能比≤50% |

### 蛋白质声称

| 声称 | 条件 |
|------|------|
| 蛋白质来源/含有蛋白质 | ≥10% NRV/100g(固体) 或 ≥5% NRV/100mL(液体) |
| 高蛋白/富含蛋白质 | ≥20% NRV/100g(固体) 或 ≥10% NRV/100mL(液体) |

### 脂肪声称

| 声称 | 条件 |
|------|------|
| 无/不含脂肪 | ≤0.5 g/100g或100mL |
| 低脂肪 | ≤3 g/100g(固体) 或 ≤1.5 g/100mL(液体) |
| 瘦 | 脂肪含量≤10 g/100g，仅限畜肉类和禽肉类 |
| 无/不含饱和脂肪 | ≤0.1 g/100g或100mL |
| 低饱和脂肪 | ≤1.5 g/100g(固体) 或 ≤0.75 g/100mL(液体)，且饱和脂肪供能比≤10% |
| 无/不含反式脂肪酸 | ≤0.3 g/100g或100mL |

### 糖/碳水化合物声称

| 声称 | 条件 |
|------|------|
| 无/不含糖 | ≤0.5 g/100g或100mL |
| 低糖 | ≤5 g/100g或100mL |
| 无乳糖 | ≤0.5 g/100g(mL)，仅限乳品类 |
| 低乳糖 | ≤2 g/100g(mL)，仅限乳品类 |

### 膳食纤维声称

| 声称 | 条件 |
|------|------|
| 膳食纤维来源/含有膳食纤维 | ≥3 g/100g(固体) 或 ≥1.5 g/100mL(液体) |
| 高/富含膳食纤维 | ≥6 g/100g(固体) 或 ≥3 g/100mL(液体) |

### 钠声称

| 声称 | 条件 |
|------|------|
| 无/不含钠 | ≤5 mg/100g或100mL |
| 极低钠/极少钠 | ≤40 mg/100g或100mL |
| 低钠 | ≤120 mg/100g或100mL |

### 维生素/矿物质声称

| 声称 | 条件（每100g） |
|------|---------------|
| X来源/含有X | ≥15% NRV(固体) 或 ≥7.5% NRV(液体) |
| 高/富含X | ≥30% NRV(固体) 或 ≥15% NRV(液体) |
| 含有多种维生素/矿物质 | 3种及以上符合"含有"声称要求 |
| 富含多种维生素/矿物质 | 3种及以上符合"富含"声称要求 |

## 比较声称要求

与参考食品比较，减少或增加25%以上方可声称：

| 声称类型 | 要求 |
|---------|------|

| 增加蛋白质/膳食纤维/维生素/矿物质 | 增加25%以上 |

参考食品来源：同一企业同类食品 或 《中国食物成分表》

## 营养成分作用声称用语（摘要）

详见GB 28050-2025 附录D，以下为常见用语：

### 蛋白质
- 蛋白质是人体的主要构成物质并提供多种氨基酸
- 蛋白质有助于组织的形成、修复和生长
- 蛋白质有助于肌肉的增长和维持

### 脂肪
- 每日膳食中脂肪提供的能量比例不宜超过总能量的30%
- 长期高脂肪摄入不利于维持正常体重和体脂水平

### 糖
- 长期高糖摄入可增加龋齿和肥胖发生的风险

### 膳食纤维
- 膳食纤维是低能量物质
- 膳食纤维有助于维持正常的肠道功能

### 钠
- 成人每日食盐的摄入量不宜超过5g
- 长期高盐摄入可以导致血压升高

### 钙
- 钙是人体骨骼和牙齿的主要组成成分
- 钙有助于骨骼和牙齿的发育
- 钙是正常的神经和肌肉功能所必需的

### 维生素C
- 维生素C有抗氧化作用
- 维生素C有助于维持骨骼和牙龈的健康
- 维生素C可以促进铁的吸收
