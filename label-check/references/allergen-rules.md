# 过敏原标注规则

## 概述

食品过敏原是引起人体过敏反应的物质，标签中必须清晰标注。

## 中国规定的主要致敏物质（8类）

| 序号 | 致敏物质 | 常见食品 |
|------|---------|---------|
| 1 | 含有麸质的谷物 | 小麦、黑麦、大麦、燕麦等 |
| 2 | 甲壳类及其制品 | 虾、蟹、龙虾等 |
| 3 | 鱼类及其制品 | 各种鱼类 |
| 4 | 蛋类及其制品 | 鸡蛋、鸭蛋等 |
| 5 | 花生及其制品 | 花生、花生油等 |
| 6 | 大豆及其制品 | 大豆、豆腐、豆浆等 |
| 7 | 乳及乳制品 | 牛奶、奶酪、乳粉等 |
| 8 | 坚果及其制品 | 杏仁、核桃、腰果、榛子等 |

## 标示格式

### 方式一：直接标注

```
致敏原信息：含有麸质的谷物、大豆、乳及乳制品
```

### 方式二：在配料表中标注

在含致敏物质的配料后标注：

```
小麦粉（含有麸质）、大豆油、乳清蛋白
```

### 方式三：警示语

```
过敏原信息：本产品含有麸质、大豆、奶制品
```

## 常见膨化食品致敏原

| 配料 | 致敏物质类别 |
|------|-------------|
| 小麦粉 | 含有麸质的谷物 |
| 玉米粉 | 一般不致敏 |
| 大豆油 | 大豆 |
| 乳清蛋白 | 乳及乳制品 |
| 鸡蛋粉 | 蛋类 |
| 花生碎 | 花生 |
| 芝士粉 | 乳及乳制品 |
| 虾粉 | 甲壳类 |
| 鸡粉/鸡精 | 可能含蛋类 |

## 膨化食品常见过敏原组合

### 玉米片（基本款）

```
配料：玉米粉、植物油、白砂糖、食用盐、食品添加剂（碳酸氢钠）、复合调味料

过敏原风险：低（玉米一般不过敏）
建议标注：无特殊标注要求
```

### 芝士味玉米片

```
配料：玉米粉、植物油、芝士粉、乳清蛋白粉、食用盐、食品添加剂、复合调味料

过敏原风险：乳及乳制品（奶酪、乳清蛋白）
建议标注：致敏原信息：含有乳及乳制品
```

### 海苔味玉米片

```
配料：玉米粉、植物油、海苔、食用盐、食品添加剂、复合调味料

过敏原风险：一般无（海苔不属于主要致敏物质）
建议标注：无特殊标注要求
```

### 麻辣味鸡味玉米片

```
配料：玉米粉、植物油、白砂糖、食用盐、鸡粉、食品添加剂、复合调味料

过敏原风险：可能含蛋类（鸡粉中可能含有）
建议标注：致敏原信息：含有蛋类及制品（如适用）
```

## 交叉污染提示

当无法确保产品不含致敏物质时，应标注：

```
致敏原信息：本产品生产线可能含有花生、坚果
```

或

```
致敏原信息：本产品与含有麸质的食品共用生产线
```

## 检查清单

### 必检项目

- [ ] 配料表中是否含有8大致敏物质？
- [ ] 如含有致敏物质，是否已标注？
- [ ] 标注格式是否符合要求？
- [ ] 是否需要添加交叉污染提示？
- [ ] 过敏原标注位置是否醒目？

### 常见遗漏

- [ ] 芝士粉/乳清蛋白 → 未标注乳制品
- [ ] 鸡粉 → 未考虑蛋类可能性
- [ ] 花生碎 → 未标注花生
- [ ] 小麦面粉 → 未标注麸质

## 案例

### 案例：芝士味玉米片过敏原标注

**错误做法**：
```
配料表：玉米粉、植物油、白砂糖、芝士粉、食用盐
（未标注过敏原信息）
```

**正确做法**：
```
配料表：玉米粉、植物油、白砂糖、芝士粉、食用盐
致敏原信息：含有乳及乳制品
```
