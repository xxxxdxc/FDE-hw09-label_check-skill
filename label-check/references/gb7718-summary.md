# GB 7718-2011 核心摘要

> 食品安全国家标准 预包装食品标签通则  
> 发布日期：2011-04-20 | 实施日期：2012-04-20

## 基本要求

1. **真实性**：应真实、准确，不得以虚假、夸大、使消费者误解或欺骗性的文字、图形等方式介绍食品
2. **语言**：应使用规范的汉字，同时使用的外文应与汉字有对应关系
3. **图案**：不得有封建迷信、色情、恐怖、涉及疾病防治的内容
4. **真实属性**：应反映食品的真实属性，不得使用让消费者误解或混淆食品真实属性的名称

## 食品名称

### 命名原则

| 问题 | 示例 | 正确做法 |
|------|------|---------|
| 虚假名称 | "奶茶味饼干"（无奶） | "XX饼干"或"XX味饼干" |
| 混淆名称 | "某品牌"（植物蛋白饮料） | 应标注"植物蛋白饮料" |
| 谐音借用 | "某零食品牌"（零食） | 可能涉及不良谐音，谨慎使用 |

### 常见食品名称问题

- **膨化食品**：应标注具体品类，如"玉米片"、"薯片"
- **复合产品**：如含芝士和玉米片，应明确"芝士味玉米片"
- **口味标示**：应使用"XX味"，不能仅写口味名称

## 配料表

### 基本规则

1. **真实属性名称**：配料应使用真实属性名称
2. **复合配料**：如复合配料已有国家标准，其名称可代用，否则应将复合配料的原始配料展开列出
3. **添加剂**：直接加入食品的添加剂应逐个列出

### 配料名称规范

| 错误表述 | 正确表述 |
|---------|---------|
| 食用香精 | 复合调味料（推荐）或食用香精 |
| 氢化植物油 | 氢化植物油（注意反式脂肪酸标示） |
| 消泡剂 | 应使用学名 |

### 配料排序规则

按递减顺序排列，加入量不超过2%的配料可不按递减顺序排列

## 净含量

### 标示规则

| 计量方式 | 单位 | 示例 |
|---------|------|------|
| 质量 | kg、g | 500g |
| 体积 | L、mL | 500mL |
| 体积（固体） | mL | 250mL |

### 字符高度要求

| 净含量 | 字符最小高度 |
|--------|-------------|
| ≤50g/mL | 3mm |
| 50~200g/mL | 4mm |
| 200~1000g/mL | 6mm |
| >1000g/mL | 9mm |

## 生产日期和保质期

### 标示方式

| 保质期 | 标示方式 |
|--------|---------|
| 有限期至 | 最好在XX日前食（使）用 |
| 生产日期和保质期 | 生产日期：XXXX年XX月XX日<br>保质期：XX个月/天 |

### 日期格式

- 应按年、月、日顺序标示
- 年代应标示4位数字

## 贮藏条件

应标注食品的贮藏条件，如：

- 常温保存
- 冷藏保存（2-8℃）
- 密封存放于阴凉干燥处
- 避光保存

## 生产许可证编号

### 标示位置

| 类型 | 位置 | 格式 |
|------|------|------|
| 食品生产许可证编号 | 包装背面或正面 | SC + 14位数字 |
| QS标志 | 已取消 | 无需标注 |

### 委托加工标注

| 情况 | 标注方式 |
|------|---------|
| 委托方生产 | 委托方名称、地址 + "委托" + 受托方名称 |
| 受托方生产 | 受托方名称、地址 + 受托方生产许可证编号 |

## 联系方式

### 标示要求

| 项目 | 要求 |
|------|------|
| 电话 | 应标注，可接通 |
| 地址 | 应标注完整地址 |
| 邮编 | 可选 |

### 联系方式格式

```
联系方式：400-XXX-XXXX
地址：XXXX
邮编：XXXXXX
```

## 产地

### 标示规则

| 类型 | 标示内容 |
|------|---------|
| 国内生产 | 标注到地市级 |
| 进口食品 | 原产国/地区名称 |

## 食品标签检查清单

### 必检项目

- [ ] 食品名称是否反映真实属性？
- [ ] 配料表是否完整、真实？
- [ ] 净含量单位是否正确、字符高度是否达标？
- [ ] 生产日期和保质期是否清晰、格式正确？
- [ ] 贮藏条件是否标注？
- [ ] 联系方式是否可接通？
- [ ] 生产许可证编号是否正确？
- [ ] 产地是否标注到地市级？

### 常见问题

- [ ] 无绝对化宣称（"最好"、"第一"等）
- [ ] 无虚假或夸大描述
- [ ] 无封建迷信或不良图案
- [ ] 无涉及疾病预防或治疗的表述
